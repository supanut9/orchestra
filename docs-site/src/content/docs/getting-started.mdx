This guide is for contributors and users who want to build Orchestra from source. For pre-built binaries see the [Releases page](https://github.com/supanut9/orchestra/releases) (available after v0.1).

## Prerequisites

| Tool | Minimum version | Install |
|------|----------------|---------|
| Node.js | 22 LTS | https://nodejs.org or `fnm install 22` |
| pnpm | 10 | `npm install -g pnpm@10` |
| Rust + Cargo | stable (current) | https://rustup.rs |
| Git | 2.38+ | https://git-scm.com |

<Aside type="note" title="Linux only">
Orchestra's Tauri shell requires several system libraries on Linux:

```sh
# Debian / Ubuntu
sudo apt-get update && sudo apt-get install -y \
  libwebkit2gtk-4.1-dev libappindicator3-dev librsvg2-dev \
  patchelf libssl-dev libgtk-3-dev libayatana-appindicator3-dev \
  libsoup-3.0-dev libjavascriptcoregtk-4.1-dev
```
</Aside>

## Clone and install

```sh
git clone https://github.com/supanut9/orchestra.git
cd orchestra
pnpm install
```

`pnpm install` wires up all JavaScript / TypeScript workspaces. Rust dependencies are fetched lazily by Cargo on first build.

## Development mode

<Steps>
1. Start the Tauri dev server (hot-reloads both the React UI and Rust backend):

   ```sh
   pnpm tauri dev
   ```

2. The first run takes a few minutes while Cargo compiles all crates.
   Subsequent runs are much faster thanks to incremental compilation.

3. The app window opens automatically once the build completes.
</Steps>

## Running the test suite

```sh
# TypeScript / JavaScript (Vitest)
pnpm test

# Lint + type-check
pnpm lint
pnpm typecheck

# Rust
cargo check --manifest-path apps/desktop/src-tauri/Cargo.toml
cargo clippy --manifest-path apps/desktop/src-tauri/Cargo.toml --all-targets -- -D warnings
```

## Building a release binary

```sh
pnpm tauri build
```

Artifacts land in `apps/desktop/src-tauri/target/release/bundle/`: `.dmg` on macOS, `.deb` + `.AppImage` on Linux, `.msi` on Windows.

## Configuring AI providers

When you first launch Orchestra, open **Settings → AI Providers** and enter your API key(s). Keys are stored in Tauri's secure local store and never leave your machine.

<Tabs>

  </TabItem>
  <TabItem label="OpenAI">

  <TabItem label="OpenRouter">

  </TabItem>
</Tabs>

## Common issues

**`cargo: command not found`** — Run `source "$HOME/.cargo/env"` after installing via rustup.

**`libwebkit2gtk-4.1-dev: unable to locate package`** — Ensure `universe` is in your apt sources: `sudo add-apt-repository universe && sudo apt-get update`.

**`pnpm install` fails with peer dependency errors** — Make sure you are on pnpm 10: `pnpm --version`.
